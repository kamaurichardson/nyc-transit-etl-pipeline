
# NYC Transit ETL Pipeline

## Overview
An end-to-end data engineering project using
Python, SQL, Apache Spark, and Databricks.

## Project Goals
- Extract public NYC transit data
- Clean and validate datasets
- Transform data using Python and PySpark
- Load processed data into structured storage
- Analyze transit trends using SQL
- Develop a repeatable ETL workflow

## Technologies
- Python
- Pandas
- SQL
- Apache Spark / PySpark
- Databricks

## Project Status
Day 1: Initial setup

## Getting Started
1. Clone the repository.
2. Create a Python virtual environment.
3. Install project dependencies.
4. Run the pipeline using:
   python src/pipeline.py
